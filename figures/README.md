## Beyond the Prompt

`beyond-the-prompt.pdf` is the figure supplied by the site owner. It is embedded
directly using the browser's PDF viewer, with an always-visible link to open the
PDF in a new tab. No conversion library or website dependency is required.
Inline PDF support and viewer controls vary by browser, especially on mobile;
the direct link remains available regardless.

If an SVG or PNG is exported on another machine later, it can replace the
`<object>` inside this paper's `.publication-figure` with an `<img>`. The modal
already includes the figure automatically, so no JavaScript change is needed.
